# Weight without an outfit dependency

Weight is available whenever Hex Appeal's native shaping adapter and active body are ready. No outfit installation, source file or path is required. Height remains independent, including shortest Height with maximum Weight.

Weight adjusts the same native limb/waist parameters and range while retaining selected breast/butt shaping values. This removes an old file-presence gate; it does not bake body geometry from another mod into Hex Appeal. The historical visual reference remains credited.

The core-only release includes no Dancer integration. Legacy outfit path and colour fields remain inert preferences for settings compatibility. They are not scanned, loaded, mounted or used to enable Weight. Old outfit choices appear unavailable; Default remains selectable.

Missing Venus Body for Damiane or Instant Surgery, an unmounted body or an actual incompatible native interface still stops shaping. Weight is not arbitrary cloth regeneration or a universal outfit-fit guarantee.

The independent-Weight native test covered 36 regional/height extreme cases and eight weighted VENUS/FLAT cases without Hex's Hentai Preset. Existing eleven pose comparisons matched the prior outputs exactly. Current exact-binary results are recorded in [release verification](VERIFICATION-1.0.0.md).
