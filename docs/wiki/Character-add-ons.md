# Character add-ons

My character packs add NPCs to Hex Appeal’s Shape and Wardrobe. They follow your VENUS or Vanilla body choice. Download the optional packs from the `packs/` folder in the [1.1.6 Release Bundle](https://github.com/TAS-69/HexAppeal/releases/tag/v1.1.6). They are unchanged from 1.1.3.

| Alida | 1.0.0 | 1.1.3 | 415 |
| Naira | 1.0.0 | 1.1.3 | 1004236, 412, 444 |

## Install and use

1. Close Crimson Desert. Extract the bundle and import each pack ZIP you want into DMM. Enable the packs and mount.
2. Open **F9 → Settings → Character patches** to see or toggle the packs. These six packs start enabled on a fresh profile.
3. Select the character in F9. On 1.1.3 and later, open **Woosa & Maegu** in the sidebar and pick either character in the dropdown. Each keeps her own Shape and Wardrobe. Earlier supported cores list them separately.

Naira and Rucchia have **Combine instances** beside the character picker. While checked, their loaded records share edits. **Cancel** restores each previewed record’s previous outfit, and **Follow game** restores each record’s own game outfit. Untick **Combine instances** to edit each record separately.

The roster holds 250 add-on records alongside the six built-in characters. Each independent character or alternate game record uses a slot. Your pack checkbox choices and customisations are kept when you update.

To build a pack, see the [manifest guide](../character-addons.md) and the [Rucchia and Stranger example](../../runtime/sdk/examples/character-variants/README.md).
