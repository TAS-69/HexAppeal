# Native integration

The development runtime references the installed VENUS Human Body or Elf Body, reads the external Hex preset and calls/hooks the loaded Instant Surgery native interfaces. When compatible Body Physics is loaded, coordinated pose acknowledgements preserve its update route. These integrations use checked private native signatures and layout constants; no upstream ASI or preset implementation is distributed. Development 0.5.8 reports [per-feature compatibility](../docs/DEPENDENCY-COMPATIBILITY.md) and resolves executable versioned exports by name rather than requiring their old address.

Wardrobe uses recognized default outfit ownership, game-thread assembly switching, acknowledgements and settling. It restores saved choices as actors load. Dancer references only separately installed original models/properties/colours. Generic providers can declare engine parts, complete prefab matrices or provider-owned controls. See `sdk/README.md` and `sdk/AUTHOR-PATCH-GUIDE.md`.

Readable unverified dependency versions remain usable with warnings. Missing files/invalid paths disable the affected features. Actual incompatible interfaces or changed ownership reject unsafe operations. No universal future-version or arbitrary mesh-fitting guarantee is made.

Public release numbers are read from `VERSION`; development numbers are separate. Exact offline results and the rebuilt ASI hash accompany the release. Live rendering evidence has the limits described in the Player Guide's Compatibility page.
