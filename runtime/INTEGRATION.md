# Native integration

The runtime references the installed VENUS Human/Elf body, reads the external Hex preset and calls/hooks Instant Surgery's checked native shaping interfaces. Compatible loaded Two Reasons Body Physics uses its pose acknowledgement interface. No upstream ASI, preset implementation or downloaded body is distributed.

Weight uses native shaping directly. Wardrobe is generic: recognized default ownership, game-thread assembly switching, acknowledgements, settling and SDK providers. Providers retain their own assets and register real names, controls, readiness, visibility parts or complete prefab matrices. The optional resource refresh API remains available to them.

No Dancer-specific source discovery, model routes, palette implementation, setup or built-in selection is supplied. Legacy saved outfit/colour/path fields are preserved only as inert settings compatibility. A future outfit integration must ship separately and use the public SDK.

Unverified readable dependency versions warn. Missing paths or actual incompatible interfaces block affected operations. Private native layout changes still need adapter work. See [dependency compatibility](../docs/DEPENDENCY-COMPATIBILITY.md), [SDK](sdk/README.md) and [verification](../docs/VERIFICATION-1.0.0.md).
