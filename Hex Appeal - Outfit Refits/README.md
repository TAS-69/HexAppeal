# Hex Appeal - Outfit Refits

Public package **1.0.0** by **TAS-69**. Close the game, import this folder/archive through Desert Mod Manager, enable it, review conflicts and mount.

Optional add-on requiring Hex Appeal - Bodies and VENUS Elf Body. Contains forty game-derived default garments fitted to the VENUS 2.6 baseline. Shared boot routes 0160, 0161 and 0163 may conflict with VENUS Armor Refit.

The separate Runtime package supplies the F9 editor, mixed shapes and Wardrobe. See the Player Guide for dependencies, priority and known limits. Downloaded mod files are not included. Original patches/code are 0BSD; game-derived garment data remains Pearl Abyss content.
