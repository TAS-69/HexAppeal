# Hex Appeal - Bodies

Public package **1.0.0** by **TAS-69**. Close the game, import this folder/archive through Definitive Mod Manager, enable it, review conflicts and mount.

Requires the separately installed Venus Body for Damiane (Elf Body). Seven appearance references cover six human witches and alternate Bari; no body model is included.

The separate Runtime package supplies the F9 editor, mixed shapes and Wardrobe. See the Player Guide for dependencies, priority and known limits. Downloaded mod files are not included. Original patches/code are 0BSD; game-derived garment data remains Pearl Abyss content.
