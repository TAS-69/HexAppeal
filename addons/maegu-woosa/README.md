# Hex Appeal · Woosa & Maegu

This optional add-on adds Maegu and Woosa to the main **F9** character list. It follows Hex Appeal's body selection and requires Hex Appeal 1.0.5 or later.

1. Close Crimson Desert.
2. Import the ZIP through **DMM → Mods → Import**, enable **Hex Appeal – Maegu and Woosa**, and mount.
3. Launch Crimson Desert. **F9 → Settings → Character patches** shows **Woosa & Maegu** and its compatibility status. The pack starts enabled unless you previously turned it off.
4. On Hex Appeal 1.1.3, select **Woosa & Maegu** in the F9 sidebar, then pick either character in the dropdown. Earlier supported versions list each character separately. Bring the character into view to use **Shape** or **Wardrobe**. **[01] VENUS** uses your separately installed Venus Body for Damiane. **[02] Vanilla** uses her original proportions.
5. Preview gear in **Edit [HA] Wardrobe**. **Apply and save** keeps that character's outfit, **Cancel** returns to the previous outfit, and **[CD] Vanilla** restores her original equipment.

The patch identifies the characters and their stock equipment. The main Hex Appeal runtime handles shaping, equipment, SDK item options and visibility. Wardrobe uses equipment for the current body. A piece still needs to be fitted for that body to sit correctly. Base underwear controls require an existing base mesh.

Uncheck the pack in **F9 → Settings → Character patches** to suspend both characters’ controls. Recheck it to access them and their saved settings again. Restart Crimson Desert after changing the patch or body choice to reload the character appearances. To remove the pack from the game entirely, untick it in DMM, mount again and restart. If you installed the older manual preview, remove its `%LOCALAPPDATA%\HexAppeal\Characters\maegu-woosa.tsv` when switching to DMM.
